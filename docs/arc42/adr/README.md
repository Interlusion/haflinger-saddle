New ADRs take the highest number + 1 and start as Proposed. An ADR is Accepted when the maintainer accepts it; ADR-001 was accepted on 2026-11-20. Until the app's 1.0.0, Proposed and Accepted ADRs alike are edited in place; from then on, an Accepted ADR is no longer rewritten, a typo or a link aside: a change is a new ADR that supersedes it. An ADR's `Date` is the date of its last change; an edit updates it in the ADR and in its row above. Agent-drafted ADRs say so under Author.
